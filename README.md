# Auto-nbsp — плагин для Figma

Расставляет неразрывные пробелы (NBSP, U+00A0) в русском тексте по правилам типографики. Работает с выделенными текстовыми слоями, а также с текстами внутри выделенных фреймов и групп. Интерфейс на русском.

Ниже `_` обозначает неразрывный пробел.

## Как пользоваться
1. Запустите плагин и выделите текстовые слои или фрейм с текстами.
2. Окно сразу показывает два списка: где не хватает неразрывных пробелов и где стоят повторяющиеся пробелы. В заголовке каждого — сколько слоёв и мест. Клик по строке выделяет слой и фрагмент текста на холсте; список при этом остаётся прежним. Списки обновляются при смене выделения и при правке текста.
3. Кнопка «Расставить неразрывные пробелы» исправляет текст: убирает повторы пробелов и ставит неразрывные. Итог — во всплывающем уведомлении Figma.
4. Галочка «Добавить аннотацию» (запоминается) при нажатии кнопки добавляет к каждому слою аннотацию с текстом слоя.
5. Ссылка «Как работает плагин» внизу окна открывает справку с правилами; закрывается крестиком или Esc.
6. Размер окна меняется уголком в правом нижнем углу (не меньше 300 × 360) и запоминается между запусками.

При открытии плагин ничего не меняет в тексте — только показывает найденное.

## Настройка правил
В справке («Как работает плагин») четыре правила можно выключить галочками:

| Правило | Включено | Выключено |
|---|---|---|
| Четырёхзначные числа | `1_000` | `1000` (набранное `1 000` всё равно связывается) |
| Короткие слова (1–2 буквы), кроме предлогов, союзов и частиц | `я_пришёл` | `я пришёл` |
| Тире | `Рынок_— это` | `Рынок — это` |
| Повторяющиеся пробелы | исправляются и показываются в окне | не трогаются и не показываются |

По умолчанию всё включено. Настройки личные: хранятся у пользователя (clientStorage) и действуют во всех файлах. Если что-то выключено, внизу окна видно «Отключено правил: N» (клик открывает настройки); в справке есть «Вернуть по умолчанию». Списки ошибок в окне учитывают настройки.

Остальные правила работают всегда.

## Что делает с текстом
Сначала повторяющиеся пробелы заменяются одним (см. ниже), затем плагин заменяет существующий обычный пробел на неразрывный. Новые пробелы создаются только внутри чисел. Уже стоящие NBSP и тонкие пробелы не трогаются, форматирование (шрифты, цвета, ссылки) сохраняется.

| Случай | Результат |
|---|---|
| Числа от четырёх цифр (четырёхзначные — отключаемо) | `1_000`, `12_345`, `2_345_999`; набранное с пробелом `1 000` тоже связывается |
| Предлоги, союзы | `в_списке`, `первый и_второй`; «что», «чем» после предлога — местоимения, пробел после них обычный: `с_чем вы`, `о_чём вы` |
| Составные союзы (в том числе после запятой) | `потому_что`, `потому,_что`, `для_того,_чтобы`, `так_как`, `а_также` |
| Частицы «не», «ни», «вот», «вон», «ну», «уж», «то» | к следующему слову: `не_пошёл` |
| Частицы «бы», «б», «ли», «ль», «же», «ж» | к предыдущему слову: `я_бы пошёл`, `знаешь_ли`, `он_же ушёл`; после них пробел обычный |
| Слова из одной-двух букв (отключаемо) | `я_пришёл`, `а_он` |
| Единицы после числа | `5_лет`, `2024_г.`, `10_сек`, `100_000_руб.`, `5_тыс._руб.`, `500_г`, `20_°C`, `5_м²` |
| Проценты | `20_%` только если пробел уже был; `20%` остаётся |
| Даты | `10_ноября_2026_г.`, `в_ноябре_2026` |
| Инициалы | `А._С._Пушкин`, `Пушкин_А._С.` |
| Сокращения | `т._е.`, `и_т._д.`, `и_т._п.` |
| Номера и ссылки | `№_5`, `§_3`, `ст._12`, `п._4`, `рис._2`, `табл._1`, `гл._3` |
| Адреса | `г._Москва`, `ул._Ленина,_д._5,_кв._12` |
| Тире (отключаемо) | `Рынок_— это`: неразрывный пробел перед «—» и «–», после обычный |
| Телефоны | `+7_(495)_123-45-67`, `8_800_555-35-35` |
| Римские цифры и век | `XXI_век`, `в_XX_в.` |

Исключения для чисел: дробная часть (`3,14159`), идентификаторы (`ID12345`, `#12345`), числа с ведущим нулём, даты `2024-11-10` и `10.11.2024`, годы (`в 2024 г.`, `2024 году`, `в ноябре 2026`), телефоны (внутри них цифры не разбиваются), реквизиты после ИНН, КПП, ОГРН(ИП), БИК, ОКПО, ОКТМО, СНИЛС, р/с, к/с, «счёт», «индекс» (`ИНН 7702045051`, `ИНН/КПП 7702045051/770201001`), почтовые индексы — шесть цифр после слова «адрес» или перед «, Россия», «, г.», «, ул.», «… обл.» (`115432, г. Москва`).

## Аннотации
- Аннотации видны только на платных планах Figma. Плагин не может узнать тариф (на бесплатном плане Figma принимает аннотации без ошибок, но не показывает их), поэтому у галочки пометка «нужен платный план Figma».
- Включается галочкой «Добавить аннотацию». По умолчанию аннотация добавляется только к слоям, в тексте которых есть неразрывные пробелы.
- Вложенная галочка «Даже если в тексте нет неразрывных пробелов» (видна при включённой аннотации, по умолчанию снята, запоминается) добавляет аннотацию ко всем непустым слоям.
- Одна аннотация на слой с категорией («флагом») «Текст». Если такая категория уже есть в файле, используется она, новая не создаётся.
- Содержимое — текст слоя, где неразрывные пробелы записаны как `&nbsp;`.
- Чужие аннотации никогда не заменяются. Если у слоя уже есть другие аннотации, новая добавляется рядом.
- Аннотации «Текст» с другим содержимым (например, ссылки) не меняются.
- При повторном запуске после правки текста обновляется только аннотация плагина. Её находят по тексту, который плагин записал в слой при прошлом запуске (pluginData `nbspAnnotationLabel`), а если его нет, по совпадению с текстом слоя.

## Повторяющиеся пробелы
- Два и более пробела подряд (обычные и неразрывные) показываются в окне с маркерами (`·` обычный, `°` неразрывный).
- По кнопке группа заменяется одним пробелом. Если в группе был неразрывный, остаётся он, иначе первый пробел.
- Оставшийся пробел затем проходит обычные правила: `в  доме` → `в_доме`, `Он  пришёл` → `Он_пришёл`, `конец.  Начало` → `конец. Начало`.
- В каждом списке окна показываются первые 100 мест, остальные учитываются в счётчике.

## Устройство
- `manifest.json`, `code.js` (вся логика, чистый JS без сборки), `ui.html` (окно плагина).
- Интерфейс — HTML-окно, стилизованное под Figma через переменные `--figma-color-*` (поддерживает светлую и тёмную темы); нативных компонентов Figma для плагинов нет.
- Скорость: слой, у которого весь стиль одинаков, перезаписывается одной операцией; со смешанным стилем правка идёт по символам, чтобы не потерять форматирование.

## Разработка
- Тесты логики расстановки без Figma: `npm test` (`tests/cases.json`, `_` — NBSP). Новые эталоны: `npm test -- --update`.
- Установка в Figma: Plugins → Development → Import plugin from manifest… → `manifest.json`.
- Контекст для ИИ-агента: `CLAUDE.md`, скиллы в `.claude/skills/`.
- Не проверено в настоящем Figma: быстрая запись на слоях со смешанным стилем, выделение фрагмента, создание категории аннотаций, обновление списков при правке текста (`nodechange`).
